# Spikewave social assets

Public host for Spikewave app marketing graphics used in scheduled social posts.

Buffer's API attaches images only by fetching a public URL (it has no file upload),
and Canva's own export links expire within a day — so these live here to give
Buffer a stable `raw.githubusercontent.com` URL to fetch at publish time. Organised
by run date. Everything here is marketing material, intentionally public.
